# Jogo RPG — V1 (Etapas 1 a 12)

Projeto didático em HTML, CSS e JavaScript, aplicando POO, herança, MVC, dados mockados, DOM e localStorage.

## Execução

Abra `index.html` com a extensão Live Server do VS Code.
